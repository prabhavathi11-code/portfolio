## 🌟 Overview

A modern, responsive, and performance-focused developer portfolio designed with semantic HTML5 and vanilla CSS. Features include:
- **Clean Responsive Design**: Optimized across mobile, tablet, and ultra-wide screens.
- **Adaptive Dark / Light Theme**: Dynamic toggle with memory persistence (`localStorage`) and system preference fallback (`prefers-color-scheme`).
- **Interactive Code Terminal**: Profile representation formatted as an active API payload.
- **Production Project Showcase**: Deep dives into real production systems, FinTech analytics dashboards, Django systems, and Machine Learning classifiers.
- **HR-Optimized UX**: Quick 1-click clipboard email copy, direct links, and clear contact channels.
